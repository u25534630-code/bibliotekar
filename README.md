# Библиотекарь

Помощник для порядка в файлах на компьютере с Windows. Он знает, где что лежит,
раскладывает файлы по «книжным полкам», убирает мусор из «Загрузок» и выполняет
простые задания: их можно написать или сказать голосом.

Всё окно программы — сцена из мультфильма: старинная библиотека и сам
Библиотекарь, добрый старичок в очках. Он оживает и говорит, когда находит файл,
убирает или создаёт новую папку.

## Как установить

1. Нажмите зелёную кнопку **Code** → **Download ZIP** и распакуйте архив в любую
   папку, например в «Документы».
2. Если Windows пишет, что файл из интернета: щёлкните правой кнопкой по
   `Запустить Библиотекаря.cmd` → **Свойства** → поставьте галочку
   **«Разблокировать»** → **ОК**.
3. Запустите **`Запустить Библиотекаря.cmd`**.

Больше ничего устанавливать не нужно: хватит Windows 10 или 11.

### Первый запуск

- Библиотекарь составит каталог ваших файлов: Рабочий стол, Документы,
  Изображения, Видео, Музыка, Загрузки. Добавить или убрать папки можно клавишей **F12**.
- Когда вы впервые будете раскладывать файлы, он спросит, **где поставить книжные
  полки**: например в «Документах» или на диске D. Он создаст там папку
  `КНИЖНЫЕ_ПОЛКИ` с разделами:

  ```
  01_РАБОТА   02_МОИ_ПРОЕКТЫ   03_МОИ_РАБОТЫ   04_ЛИЧНОЕ_И_СЕМЬЯ   05_ОБУЧЕНИЕ   90_РАЗОБРАТЬ
  ```

- Чтобы он сам приходил с уборкой каждое воскресенье, откройте
  **«Ещё ▾» → «Уборка по воскресеньям…»**.

## Что он умеет

### Поиск
- Понимает обычную фразу: «найди договор аренды», «фото собаки», «презентация про отпуск».
- Окончания слов не важны. Слова «фото», «видео», «таблица», «презентация», «pdf»
  оставляют в результатах только файлы нужного типа.
- Ищет по названию, по папкам и по тексту внутри Word, PDF и TXT
  (для этого включите «Ещё ▾» → «Читать содержание документов»).
- Отвечает словами, **где лежит** файл: «на полке "Обучение", в папке "Английский"».
- Кнопки «Открыть найденное» и «Показать в папке». Список всех найденных файлов
  (**Ctrl+L**) появляется прямо поверх картины.
- Кнопка **«Сказать»** включает голосовой ввод Windows: говорите, и он сам напишет.

### Задания
Переключите **«Задание»** (F4): строка станет оранжевой. В обычном режиме
Библиотекарь только ищет и ничего не меняет.

- «удали папку старые фото»: сначала покажет, что внутри, и спросит. Всё уходит **в Корзину**.
- «открой папку курсовая».
- «создай папку для курсовой по истории»: сам подберёт полку, положит внутрь
  записку «для чего эта папка» и откроет её.
- «разбери картинки в загрузках», «сделай уборку», «обнови каталог», «отмени перенос».
- Можно просто перетащить папку или файл в окно: он спросит, что с ними сделать.

### Книжные полки
- Раскладывает файлы и целые папки по разделам. Сначала показывает **план**,
  переносит только то, что вы отметили.
- Каждый перенос записывается в журнал: **«Отменить перенос»** (F11) вернёт всё на места.

### Еженедельная уборка «Загрузок» и Рабочего стола
- Без вопросов отправляет в Корзину старые установщики программ (старше 2 недель)
  и точные копии файлов. Файлы с понятной темой ставит на полки.
- Про остальное спрашивает: список с галочками.
- Не трогает файлы младше недели, ярлыки и всё, что похоже на пароли и документы.

### Разбор картинок
- Битые картинки (те, что не открываются) отправляет в Корзину.
- Из точных копий оставляет одну.
- Похожие картинки показывает парами: вы решаете, какую оставить.
- Даёт понятные имена вместо «image (2).png»: по дате («Картинка 2026-10-11 001.png»),
  а если установлен [Claude Code](https://claude.com/claude-code), то по тому,
  что изображено («Зелёный жакет с кружевом.png»).

### Дубликаты
- Находит одинаковые файлы по содержимому, а не по имени. Лишние копии убирает в Корзину.

## Безопасность

- **Ничего не удаляет навсегда**: только в Корзину.
- Переносы и переименования можно отменить.
- Файлы, похожие на пароли, паспорта, СНИЛС, ИНН и банковские документы, без
  вашего «да» не трогает.
- Системные папки, «Загрузки» и Рабочий стол целиком удалять отказывается.

## Как настроить под себя

Откройте файл **`настройки.json`** Блокнотом. В нём два списка.

**Проекты.** Если в пути к файлу встречается одно из слов, файл поедет на полку
`02_МОИ_ПРОЕКТЫ` в папку проекта:

```json
{ "Название": "Диплом", "Слова": "диплом|вкр|выпускн", "Папка": "ДИПЛОМ" }
```

**Свои правила** — то же самое, но на любую полку:

```json
{ "Слова": "квитанц|чеки", "Полка": "04_ЛИЧНОЕ_И_СЕМЬЯ" }
```

- В «Слова» пишите начала слов маленькими буквами, разделяйте их знаком `|`.
- После правки перезапустите программу.

Ещё можно:
- поменять картинки и голос: всё лежит в папке `media`;
- выключить голос галочкой «Голос Артура».

## Клавиши

| Клавиша | Действие |
|---|---|
| F1 | подсказка |
| F2 | сказать голосом |
| F3 / F4 | режим «Поиск» / «Задание» |
| F5 | обновить каталог |
| F6 | еженедельная уборка |
| F9 | найти дубликаты |
| F11 | отменить перенос |
| F12 | папки каталога |
| Ctrl+L | список найденных файлов |
| Esc | очистить строку |

Остальное — в кнопке «Ещё ▾».

## Если что-то не работает

- **Голосовой ввод молчит.** Включите «Параметры → Конфиденциальность и защита →
  Речь → Распознавание речи в сети».
- **Не переносит файлы с Рабочего стола или из Документов.** Так бывает из-за
  антивируса: например, у Avast «Защита от программ-вымогателей» блокирует перенос.
  Приостановите её на время раскладки.
- **Программа не открывается.** Щёлкните правой кнопкой по `librarian.ps1` →
  «Свойства» → «Разблокировать».
